Start a work session on CUSTODIAN.

1. If this folder is not a Git repository yet, run `git init`, make an initial commit of everything with the message `chore: initial project skeleton`, and tell the owner in one line that version history is now on.
2. Run `git status`. If there are uncommitted changes, tell the owner briefly and ask whether to keep (commit) or discard them.
3. Read `docs/ROADMAP.md` (including the latest *Session log* entry) and skim `docs/DECISIONS.md`.
4. If `docs/DECISIONS.md` has no Godot path under *Environment*, check whether `godot` works on the command line. If not, ask the owner where their Godot executable is.
5. Run the headless import check from `CLAUDE.md` to confirm the project is healthy.
6. Tell the owner, in 3–5 short lines and plain language:
   - where we left off
   - the next task and what they'll be able to *see* when it's done
   - anything you need from them
   Then ask: "Shall I start?"
